## When to use recurring tasks

Some work happens on a regular cycle: weekly pipeline reviews, monthly account check-ins, quarterly data hygiene sweeps. Instead of remembering to create these manually each time, set them up once as recurring tasks.

## Creating a recurring task

1. Create a new task as normal (title, owner, priority, linked record)
2. Toggle **Recurring** on in the task form
3. Choose a frequency: daily, weekly, monthly, quarterly, or custom interval
4. Set which day of the week or month the task should appear
5. Optionally set an end date or a maximum number of occurrences

<Callout variant="note">
The next occurrence is created automatically when the current one is completed or when its due date passes — whichever comes first.
</Callout>

## Managing the series

Edit the recurring pattern from any instance by clicking **Edit series** on the task detail. Changes apply to future occurrences only; past completed tasks are not affected.

To stop a recurring task, open any instance and toggle **Recurring** off, or set an end date.

## Examples

| Use case | Frequency | Linked to |
|---|---|---|
| Weekly pipeline review | Every Monday | No link (team ritual) |
| Monthly account check-in | 1st of each month | Company record |
| Quarterly data cleanup | Every 3 months | No link |
| Annual contract renewal reminder | Yearly, 60 days before renewal | Contract record |
