{/* title: Managing tasks */}
{/* description: Create, assign, prioritise and complete tasks to keep your team's work visible and on track. */}

## Creating a task

Navigate to **Tasks** in the sidebar and click **New task**. Give it a title, set a priority (low, normal, high, urgent), choose a due date, and assign it to a team member. You can also link it to a contact, company or deal so it stays visible on that record's timeline.

<Callout variant="tip">
Use the command palette (Cmd+K) and type "new task" to create one from anywhere without navigating away from what you are doing.
</Callout>

## Assigning tasks

Every task has an **Owner** field. Set it when you create the task, or reassign it later from the task detail view. Assignment changes are recorded in the audit trail, so you can always see who was responsible at any point.

Tasks can also be assigned automatically by automation rules — see the automation section for round-robin and rule-based routing.

## Priority and status

Tasks carry both a priority and a status:

| Priority | When to use |
|---|---|
| Urgent | Must be done today, blocks something critical |
| High | Important, needs attention this week |
| Normal | Standard work, due on the date set |
| Low | Nice to have, do when capacity allows |

Status moves through **Open → In progress → Completed**. Mark a task complete from the list view, the detail view, or by dragging it to the Done column on the kanban board.

## Bulk operations

Select multiple tasks using the checkboxes on the left of the list view, then use the bulk action bar to:

- Reassign all selected tasks to a different owner
- Change priority or due date in batch
- Mark all as complete
- Delete (moves to trash with undo)

## Linking tasks to records

A task linked to a deal appears on that deal's activity timeline. This means anyone viewing the deal sees what work is outstanding. Link tasks to:

- A contact (follow-up calls, onboarding steps)
- A company (account review, quarterly check-in)
- A deal (proposal drafting, contract review)
- A project (milestone deliverables)

## Due date behaviour

When a task passes its due date without being completed, it appears in the **Overdue** filter and the owner receives a notification. Managers can view all overdue tasks across their team from the task list by filtering on status and date.
