## What task templates solve

When onboarding a new customer, reviewing a contract, or running a quarterly check-in, the same set of tasks comes up every time. Templates let you define that set once and apply it in one click.

## Creating a template

1. Go to **Settings > Task templates**
2. Click **New template**
3. Give the template a name and description
4. Add tasks: each with a title, relative due date (e.g. "3 days after creation"), default owner or role, priority, and optional linked entity type
5. Save the template

<Callout variant="note">
Relative due dates mean the template works regardless of when it is applied. "Day 1" is always the day you use the template.
</Callout>

## Applying a template

From any deal, contact or project detail view, click **Apply task template** and choose the template. All tasks are created immediately with:

- Due dates calculated from today
- Owners assigned as defined (or defaulting to you)
- Links to the record you applied it from

## Editing templates

Changes to a template do not affect tasks that have already been created from it. They only apply to future uses.

## Example templates

| Template | Tasks included | Typical trigger |
|---|---|---|
| New customer onboarding | Welcome email, data migration, training call, 30-day check-in | Deal marked Won |
| Contract renewal | Review terms, prepare quote, send for signature, follow up | 60 days before expiry |
| Quarterly account review | Pull usage data, schedule call, prepare deck, send summary | Start of quarter |
