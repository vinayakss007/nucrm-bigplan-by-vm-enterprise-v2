## Overview

NuCRM is designed for speed. Once you know the interface layout and keyboard shortcuts, you can move between contacts, deals, and tasks in seconds without reaching for your mouse. This guide covers everything you need to navigate confidently.

## The sidebar

The left sidebar is your primary navigation tool. It is always visible and provides instant access to every major section:

### Main sections

- **Dashboard** - Your personalized overview with key metrics and recent activity
- **Contacts** - All people in your database
- **Companies** - Organizations linked to your contacts
- **Deals** - Your sales pipeline and deal records
- **Tasks** - Personal and team task lists
- **Calendar** - Meetings, follow-ups, and scheduled events
- **Communication** - Unified inbox for email, WhatsApp, and SMS
- **Reports** - Dashboards and custom analytics
- **Automation** - Workflow builder and active sequences

### Sidebar behavior

- Click any section to expand it and see sub-items
- Hover over the sidebar edge to collapse it into icon-only mode on desktop
- On mobile, swipe from the left edge or tap the menu icon to open the sidebar

<Callout variant="tip">
Pin your most-used sections to the top of the sidebar by right-clicking a section name and selecting "Pin to top." This keeps your workflow front and center regardless of how many modules are active.
</Callout>

## The command palette

The command palette is the fastest way to find anything in NuCRM:

### Opening the command palette

Press **Cmd+K** (Mac) or **Ctrl+K** (Windows/Linux) to open the command palette overlay.

### What you can do

- **Search contacts** - Type a name, email, or phone number
- **Search deals** - Type a deal name or amount
- **Navigate** - Type a page name (for example, "Pipeline" or "Settings")
- **Run actions** - Type commands like "Create contact" or "New deal"
- **Search help** - Type a question to find relevant documentation

### Using the command palette

1. Press **Cmd+K** to open
2. Start typing your search term
3. Use arrow keys to highlight a result
4. Press **Enter** to navigate to it
5. Press **Escape** to close without acting

Results are grouped by type (Contacts, Deals, Pages, Actions) so you can quickly identify the correct result.

## Keyboard shortcuts

NuCRM supports dozens of keyboard shortcuts for power users:

| Shortcut | Action |
|----------|--------|
| Cmd+K / Ctrl+K | Open command palette |
| Cmd+N / Ctrl+N | Create new record (context-aware) |
| G then D | Go to Dashboard |
| G then C | Go to Contacts |
| G then P | Go to Pipeline |
| G then T | Go to Tasks |
| G then R | Go to Reports |
| Shift+? | Show all keyboard shortcuts |
| Escape | Close modal or panel |
| J / K | Move up/down in list views |
| Enter | Open selected record |
| Cmd+S / Ctrl+S | Save current form |

<Callout variant="note">
The "G then" shortcuts use a two-key sequence. Press G, release it, then press the second key within one second. If the shortcut does not trigger, ensure you are not focused inside a text input field.
</Callout>

## The top bar

The top bar provides contextual tools that change based on where you are:

### Global elements

- **Breadcrumb trail** - Shows your current location (for example, Contacts > John Smith)
- **Quick actions button (+)** - Create a new contact, deal, task, or note from anywhere
- **Notification bell** - Shows unread alerts, import progress, and system messages
- **Profile avatar** - Access your personal settings, theme toggle, and sign-out

### Contextual elements

When viewing a list (like Contacts), the top bar shows:

- **Filter bar** - Apply and combine filters to narrow results
- **View selector** - Switch between list, kanban, and table views
- **Sort control** - Change the sort field and direction
- **Bulk actions** - Appears when records are selected

## Dark mode

NuCRM supports a dark interface theme that reduces eye strain during extended sessions:

1. Click your **profile avatar** in the top-right corner
2. Select **Appearance**
3. Choose **Dark**, **Light**, or **System** (follows your operating system preference)

The change applies immediately across all pages without requiring a refresh.

## Customizing your layout

### Column visibility

In list views, control which columns are visible:

1. Click the **Columns** button above the list
2. Check or uncheck fields to show or hide them
3. Drag fields to reorder columns
4. Click **Apply**

### Saved views

Save your current filter and column configuration as a named view:

1. Set up your desired filters and columns
2. Click **Save view**
3. Enter a name (for example, "Hot leads in California")
4. Choose to keep the view private or share it with your team
5. Access saved views from the view selector dropdown

<Callout variant="info">
Shared views are visible to everyone in your workspace but only the creator or an admin can modify them. Team members can duplicate a shared view to create their own customized version.
</Callout>

## Mobile navigation

On mobile devices, NuCRM adapts its layout:

- The sidebar becomes a slide-out drawer accessible via the menu icon
- Lists display in a card format optimized for touch interaction
- The command palette works identically, triggered by tapping the search icon
- Swipe gestures are supported for quick actions (swipe left on a contact to log a call, swipe right to send email)
