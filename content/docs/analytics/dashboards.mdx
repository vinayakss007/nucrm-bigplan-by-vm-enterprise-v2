## What dashboards show

A dashboard is a grid of widgets, each showing a single metric or chart. Widgets pull from the same data your reports use, but display it as a number, bar chart, line chart, funnel or pie chart.

## Creating a dashboard

1. Go to **Reports > Dashboards**
2. Click **New dashboard** or start from a template
3. Add widgets by clicking **Add widget** and choosing a type:
   - **Metric** — a single number (e.g. "Deals closed this month: 14")
   - **Bar chart** — grouped comparison (e.g. deals by stage)
   - **Line chart** — trend over time (e.g. revenue by month)
   - **Funnel** — conversion rates through pipeline stages
   - **Pie/Donut** — proportional breakdown (e.g. leads by source)
   - **Table** — top-N list (e.g. top 5 reps by closed revenue)
4. Configure each widget: choose the entity, filters, grouping and metric
5. Drag widgets to arrange the grid layout
6. Save

<Callout variant="note">
Dashboards refresh on page load and can be set to auto-refresh at intervals (every 5, 15 or 30 minutes) for display on a wall monitor.
</Callout>

## Templates

NuCRM includes dashboard templates to get you started:

- **Sales overview** — pipeline value, deals by stage, revenue trend, top reps
- **Support overview** — open tickets, SLA compliance, CSAT trend, response time
- **Marketing** — leads by source, form conversions, sequence performance

Start from a template and customise: add, remove and rearrange widgets.

## Visibility and roles

Each dashboard has a visibility setting:

- **Everyone** — all workspace users see it
- **Specific roles** — only users with selected roles see it (e.g. managers only)
- **Personal** — only you

This lets you create an executive dashboard that shows revenue without cluttering a rep's workspace.

## Full-screen mode

Click the expand icon to show a dashboard full-screen — useful for TV displays in a sales office.
