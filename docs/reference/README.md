# NuCRM Reference Supplements

Deep-reference material that complements the main [Public](../public/README.md) and
[Super-Admin](../admin/README.md) documentation. These are added **separately** so they can evolve
(and be reviewed) independently of the core guides.

| Reference | For whom | What's inside |
| --- | --- | --- |
| [API Examples](./api-examples.md) | Developers | Copy-paste request/response examples per resource |
| [Data Model Reference](./data-model.md) | Engineers, integrators | The ~223-table schema, grouped by domain |
| [Module Authoring Guide](./module-authoring.md) | Extension developers | Build a pluggable module with the SDK |
| [Roadmap & Backlog](./roadmap.md) | Maintainers | Tracked work items and task division |

> These supplement — they don't replace — the [OpenAPI spec](../../public/api/openapi.yaml)
> (`/api-docs`), the Drizzle schema in [`drizzle/schema/`](../../drizzle), and the GitHub issue
> tracker, which remain the sources of truth.
