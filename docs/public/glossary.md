# Glossary

Terminology used across NuCRM and this documentation.

| Term | Definition |
| --- | --- |
| **Activity** | A logged interaction (call, email, meeting, note) shown on a record's timeline. |
| **AI credits** | Per-workspace units consumed by AI features; tracked and budgeted. |
| **API key** | A secret credential for server-to-server API access, scoped to one workspace. |
| **Assignment rule** | A rule that automatically routes leads/contacts to an owner. |
| **Automation rule** | An event-based "if this, then that" automation. |
| **Company** | An organization record grouping related contacts. |
| **Contact** | An individual person record. |
| **CSAT** | Customer Satisfaction — feedback collected on resolved tickets. |
| **CSRF token** | A token that protects cookie-based mutations from cross-site request forgery. |
| **Custom field** | An admin-defined extra field on a record. |
| **Deal** | A sales opportunity tracked through a pipeline. |
| **DLP** | Data Loss Prevention — policies to monitor/prevent risky data exposure. |
| **Follow-up** | A lightweight reminder to re-engage a record. |
| **Lead** | A potential customer who hasn't yet been qualified into a contact/deal. |
| **Lead scoring** | A score indicating a lead's fit/engagement (BANT + custom rules). |
| **Lead warming** | Automated nurturing of leads with scheduled touchpoints. |
| **Module** | A pluggable mini-app that adds pages, settings, and permissions to the CRM. |
| **OpenAPI** | The machine-readable API specification (`public/api/openapi.yaml`). |
| **Pipeline** | An ordered set of stages that deals move through. |
| **Plan** | The subscription tier that sets a workspace's features and limits. |
| **Plugin** | A connection to an external API defined with a URL + credentials (plugin engine). |
| **Portal / Customer Portal** | The branded, self-service area for a workspace's customers. |
| **RBAC** | Role-Based Access Control — permissions granted via roles. |
| **Role** | A named bundle of permissions (e.g. admin, manager, sales_rep, viewer). |
| **Saved view** | A stored, filtered/sorted list view. |
| **SCIM** | A standard for automated user provisioning from an identity provider. |
| **Sequence** | A drip campaign of scheduled email steps. |
| **SLA** | Service-Level Agreement — response/resolution time targets for tickets. |
| **SSO** | Single Sign-On (SAML / OIDC / OAuth 2.0). |
| **Stage** | A step within a pipeline, with a win probability. |
| **Super-admin** | A platform operator who manages the whole NuCRM installation across all workspaces. |
| **Tenant** | A single isolated organization/workspace on the platform. |
| **Ticket** | A customer support request. |
| **Timeline** | The chronological history of activity on a record. |
| **Trash** | Where deleted records go before auto-cleanup; restorable. |
| **Webhook** | An HTTP callback delivering events (outbound) or receiving them (inbound). |
| **Workflow** | A multi-step, branching automation built on a visual canvas. |
| **Workspace** | The customer-facing name for a tenant. |
