# Support & Knowledge Base

Run a help desk with tickets and SLAs, and publish self-service articles in a knowledge base.

---

## Tickets

A **ticket** is a customer support request.

| Feature | Description |
| --- | --- |
| **Status workflow** | Move tickets through states (e.g. open → pending → resolved → closed). |
| **Replies** | Threaded replies to communicate with the customer. |
| **Internal notes** | Notes visible only to your team, not the customer. |
| **Assignment** | Assign tickets to agents; rules can auto-route. |
| **Categories & priority** | Organize and prioritize incoming tickets. |

### SLAs (Service-Level Agreements)

SLA policies set targets for response and resolution times. NuCRM tracks each ticket against its
SLA and flags **breaches** so you can act before commitments are missed. Admins configure SLA
policies in the workspace settings.

### Where tickets come from

- Agents create them directly.
- Customers submit them via the [Customer Portal](../customer-portal.md) or public ticket form.
- Inbound channels (email/webhooks) can create tickets automatically.

---

## Knowledge Base (KB)

The **knowledge base** is your library of help articles.

| Feature | Description |
| --- | --- |
| **Categories** | Organize articles into browsable categories. |
| **Rich text** | Format articles with rich content. |
| **Search** | Full-text search across articles. |
| **Public portal** | Publish articles to a customer-facing portal for self-service. |

Well-maintained KB articles deflect tickets by letting customers help themselves.

---

## CSAT

Collect **customer satisfaction (CSAT)** feedback on resolved tickets to measure and improve
support quality.
