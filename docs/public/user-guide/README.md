# User Guide — Overview & Navigation

This is the complete guide to using NuCRM day to day. Each linked page covers one area in depth.

> **Audience:** everyone who works inside a NuCRM workspace.

---

## The workspace at a glance

After you log in you're inside your **workspace** (tenant). Everything you see — records,
settings, dashboards — belongs to that workspace and is isolated from every other workspace on the
platform.

### Layout

| Element | Purpose |
| --- | --- |
| **Left navigation** | Switch between modules: Contacts, Companies, Leads, Deals, Tasks, and more |
| **Top bar** | Global search, notifications, quick-create, your profile menu |
| **Main panel** | List, kanban, or detail views for the current module |
| **Command palette** | **⌘K / Ctrl+K** — search and run actions from anywhere |

### Navigating efficiently

- **Global search** finds records across modules from the top bar.
- **Command palette (⌘K)** jumps to any page or runs quick actions.
- **Keyboard shortcuts:** **⌘1–6** for top modules; save with the on-screen save shortcut.
- **Dark mode** follows your system preference and can be toggled manually.

---

## Working with records

Most modules share the same patterns, so once you learn one you know them all.

### List views

- **Filter, sort, and choose columns**, then save the result as a **Saved View** to reuse later.
- **Inline editing** — click a cell to edit without opening the record.
- **Bulk operations** — select multiple rows to edit, assign, tag, or delete in one action.
- **Import / Export** — bring data in from CSV or export it out (availability varies by module).

### Detail views

- A **timeline** shows the full history of activity on the record.
- **Tags**, **notes**, and **custom fields** let you enrich records with your own data.
- **Related records** (e.g. a company's contacts, a deal's products) are linked and navigable.

### Safety nets

- **Undo** — destructive actions show a 10-second undo toast.
- **Trash** — deleted records go to Trash and can be restored before auto-cleanup.
- **History** — field-level change history is retained for auditing.

---

## Real-time & notifications

NuCRM pushes live updates over a realtime connection. You'll see new notifications, assignment
changes, and replies appear without refreshing. The bell icon shows unread counts in real time.

## Tips

- **Personalize** your defaults in **Settings → Preferences** (timezone, locale, notifications).
- **Set an out-of-office** so assignments route around you when you're away.
- **Localization** — switch the interface language from the language switcher if enabled.
